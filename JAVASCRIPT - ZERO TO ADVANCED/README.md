# JavaScript - Zero to Advanced (Day 252 - Day 365)

An intensive 114-day JavaScript mastery program taking you from core concepts to advanced techniques, organized into 4 progressive sections.

## 📚 Overview

This comprehensive JavaScript course spans 114 days, covering everything from fundamentals to advanced JavaScript concepts, DOM manipulation, and real-world application development. The course is structured into 4 distinct sections for systematic learning.

### Section Breakdown

## 📝 Common JavaScript Patterns

### Section 1 Example (Node.js)
```javascript
// script.js - Day 252-306
console.log('Learning JavaScript fundamentals!');

// Variables
const name = 'JavaScript';
let score = 100;

// Functions
function greet(name) {
  return `Hello, ${name}!`;
}

// Arrays
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);

console.log(greet(name));
console.log(doubled);
```

### Section 2 Example (Browser)
```html
<!-- index.html - Day 307-338 -->
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <button id="myBtn">Click Me!</button>
  <div id="output"></div>
  
  <script src="script.js"></script>
</body>
</html>
```

```javascript
// script.js
const btn = document.getElementById('myBtn');
const output = document.getElementById('output');

btn.addEventListener('click', () => {
  output.textContent = 'Button clicked!';
});
```

```css
/* style.css */
button {
  padding: 10px 20px;
  font-size: 16px;
}
```
