###### Section 1: JavaScript Core Concepts — From Basics to Functions and Data Structures

This section covers the foundational concepts of JavaScript — from its origin and variable handling to scopes, functions, loops, and essential data structures like arrays and objects. It builds the base for mastering JavaScript logic, functional programming, and structured data manipulation.

### 🧩 1. Introduction to JavaScript
JavaScript was invented by **Brendan Eich** and has evolved from ES5 to the more powerful **ES6+** versions. This part introduces JavaScript’s history, purpose, and its role as a client-side and server-side language in modern web development.

### 🔤 2. Variables and Declarations
You learned how to declare and initialize variables using:
- `var`, `let`, and `const`
- Concepts of declaration vs initialization
- Block scope, function scope, and global scope
- The **Temporal Dead Zone (TDZ)** and how it affects variable accessibility  
- **Hoisting** — how variable and function declarations are processed before execution

### 🧠 3. Scope and Execution Context
Understanding **scope** is crucial in JavaScript.  
You explored:
- Function and global scopes  
- Lexical scoping and closures  
- How JavaScript searches for variables (scope chain)

### ⚙️ 4. Data Types and Type System
You studied JavaScript’s **data types**, including:
- **Primitive types:** `string`, `number`, `boolean`, `undefined`, `null`, `symbol`, `bigint`
- **Non-primitive types:** `objects`, `arrays`, and `functions`
- **Dynamic typing:** how variable types can change at runtime
- The `typeof` operator and how it identifies data types  
- **Type coercion** and equality comparison (`==` vs `===`)

### ➕ 5. Operators in JavaScript
A deep dive into various JavaScript operators:
- **Arithmetic operators** (`+`, `-`, `*`, `/`, `%`)
- **Assignment operators** (`=`, `+=`, `-=`)
- **Comparison operators** (`==`, `===`, `!=`, `>`, `<`)
- **Logical operators** (`&&`, `||`, `!`)
- **Unary, ternary**, and **instanceof** operators  
- Practical exercises to solidify understanding

### 🔁 6. Control Flow and Loops
You explored how JavaScript controls logic flow using:
- `if`, `else if`, `else`, and `switch` statements  
- The **early return pattern** for cleaner, optimized code  
- Loops:  
  - `for` loop  
  - `while` loop  
  - `do-while` loop  
- Loop control statements: `break` and `continue`  
- Multiple sets of exercises focused on **loop logic and iteration patterns**

### 🧮 7. Functions and Functional Concepts
This section dives deep into JavaScript functions — the core of reusable programming.
You learned:
- Function declaration and invocation  
- **Parameterized functions** and **default parameters**  
- **Rest parameters** for handling variable arguments  
- **Return statements** and the **early return pattern**  
- **First-class** and **higher-order functions**  
- **Pure** vs **impure** functions  
- **Closures** and **lexical scope**  
- **IIFE (Immediately Invoked Function Expressions)**  
- **Function hoisting** and its relation to TDZ  
- Difference between **arrow** and **regular functions**  
- Understanding the behavior of `this` in different function types  

Practical mini-projects included:
- **BMI Calculator** using functions  
- **Reusable Discount Calculator**  
- **Counter Closure** demonstrating data privacy  
- **Value Transformer** using pure functions  
- **Isolated Variables** using IIFE  

### 📦 8. Arrays and Array Methods
You explored **JavaScript arrays**, learning to:
- Create and access array elements  
- Modify arrays dynamically  
- Apply core methods like:
  - `push()`, `pop()`, `shift()`, `unshift()`
  - `splice()`, `slice()`, `reverse()`, `sort()`
  - Iteration methods such as `forEach()`, `map()`, `filter()`, `reduce()`
- Completed exercises applying these methods to real-world scenarios

### 🧱 9. Objects in JavaScript
Finally, you learned about **JavaScript objects** — the building blocks of structured data:
- Object creation and initialization  
- Accessing and modifying properties  
- Understanding key-value pairs and references  
- Exercises on manipulating objects dynamically

### 🏁 Summary
By the end of this section, you developed a strong understanding of:
- JavaScript’s evolution and syntax
- Scopes, functions, and closures
- Operators and control flow
- Arrays, objects, and data manipulation  
This forms the **core foundation** for your upcoming sections on advanced JavaScript topics like DOM, asynchronous programming, and ES6+ features.
