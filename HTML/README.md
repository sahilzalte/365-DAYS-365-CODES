# HTML Learning Journey (Day 1 - Day 13)

A foundational HTML learning path covering essential HTML elements, semantic markup, and web page structure.

## 📚 Overview

This folder contains 13 days of HTML fundamentals, progressing from basic structure to advanced HTML5 elements. Each day includes practical examples with hands-on HTML files.

## 🎯 Learning Path

### Phase 1: HTML Fundamentals (Days 1-4)
- Understand HTML document structure (DOCTYPE, html, head, body)
- Learn basic HTML elements and tags
- Master text formatting and headings
- Create links and navigation structures

### Phase 2: Content Organization (Days 5-7)
- Work with lists (ordered, unordered, definition)
- Create and structure tables
- Add images and media elements
- Build forms with various input types

### Phase 3: Modern HTML (Days 8-13)
- Implement semantic HTML5 elements
- Use multimedia elements (audio, video)
- Apply HTML entities and special characters
- Follow HTML best practices

## 🚀 Getting Started

1. Open any day's folder (e.g., `DAY 1`)
2. Open `index.html` in your web browser
3. View the page source to understand the HTML structure
4. Modify and experiment with the code

## 📖 How to Use This Folder

- **Sequential Learning**: Start from Day 1 and progress through each day in order
- **Hands-on Practice**: Open files in a text editor and browser side-by-side
- **Exercises**: Complete the exercise files (.txt) for additional practice
- **Reference**: Return to specific days when you need to refresh your knowledge
