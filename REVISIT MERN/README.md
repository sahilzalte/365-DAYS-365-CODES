# Revisit MERN

Welcome to the **Revisit MERN** folder! 🎉

This folder contains all my notes, practice exercises, mini projects, and code snippets to **review and reinforce** the concepts I learned during my MERN stack journey.

---

## What’s Inside?

- **Node.js**: Backend fundamentals, npm, modules, file system, and path handling.
- **Express.js**: Request/response handling, routing, middleware, and EJS templating.
- **MongoDB**: Installation, CRUD operations, Mongoose integration with Express.
- **Tailwind CSS**: Utility-first CSS, tutorials, and UI cloning practice.
- **Hosting**: Basics of web hosting and deploying Node.js apps on Ubuntu.
- **React.js**: Components, hooks, state management, routing, and form handling.
- **Next.js**: File-based routing, server components, API routes, authentication, and deployment.

## Purpose

The goal of this folder is to:

- Strengthen my understanding of MERN technologies
- Practice coding with small projects and challenges
- Organize key learnings for quick reference
