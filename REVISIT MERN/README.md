# MERN Stack Revision & Reinforcement (Day 153 - Day 210)

A comprehensive 58-day MERN stack revision course designed to solidify and reinforce your understanding of the entire MERN technology stack.

## 📚 Overview

This folder contains a systematic revision of all MERN stack technologies, from frontend fundamentals to full-stack development. It serves as a complete refresher course, revisiting concepts learned earlier and building deeper understanding through practice.

## 🚀 Getting Started

### Prerequisites
- Completed initial MERN stack learning (Days 1-152)
- Node.js and npm installed
- Basic understanding of all MERN technologies
- Willingness to revisit and practice

### Running Projects

**Frontend Projects (HTML/CSS/JS):**
```bash
# Navigate to day folder
cd "DAY 153"

# Open in browser
# Double-click index.html or use Live Server
```

**Node.js Projects:**
```bash
cd "DAY 156"
npm install
node main.js
```

**Express.js Projects:**
```bash
cd "DAY 159"
npm install
node server.js
# Visit http://localhost:3000
```

**React Projects (Vite):**
```bash
cd "DAY 166"
npm install
npm run dev
# Visit http://localhost:5173
```

**Full-Stack Projects:**
```bash
# Terminal 1 - Backend
cd "DAY 179/backend"
npm install
npm run dev

# Terminal 2 - Frontend
cd "DAY 179/frontend"
npm install
npm run dev
```
